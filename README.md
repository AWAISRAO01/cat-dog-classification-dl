# Cat vs Dog Image Classification Using Deep Learning

## Project Overview
This project uses a Convolutional Neural Network (CNN) built with TensorFlow and Keras to classify images as cats or dogs.

## Dataset
The dataset is the Cats vs Dogs image dataset from TensorFlow Datasets.

Dataset: https://www.tensorflow.org/datasets/catalog/cats_vs_dogs

## Model Details
- Image size: 160 × 160 pixels
- Batch size: 32
- Training epochs: 5
- Optimizer: Adam
- Loss function: Binary Crossentropy
- Training accuracy: 86.89%
- Validation accuracy: 82.33%

## Trained Model Files
The trained model files are hosted on Hugging Face:

https://huggingface.co/awaisrao/cat-dog-classification-dl

The repository contains the original Keras model and weights. A TensorFlow Lite version was also generated for a smaller model footprint.
